A SMALL GUIDE

从喜欢，到唱懂

  1. 粘贴原歌词

    每句单独一行，重复段落完整保留。可以附上参考罗马音；自动识别仅识别按音节空格分开的罗马音，连续拼写请选择成对模式，混合外语请选择原歌词模式。

  2. 接入模型，开始分析

    第一次分析时会弹出模型设置。可以使用 DeepSeek、OpenAI 或其他兼容服务；填写对应的 API 根地址、模型名和自己的 API Key。密钥保存在本机浏览器。

  3. 沿着词格，一句句练习

    从上到下读罗马音、原词与词义，下面是整句译文。点击阅读工具栏的「空耳」可显示或隐藏中文空耳，按对照表在本机转换，不调用模型、不额外计费。ki、ke、hi 及表中未提供中文对应的读音保留罗马音。促音用 ~ 表示，如 ya~tte。长句可左右滑动，重复句各自完整显示。

  4. 把练习带走

    复制四行文本，导出可重新导入的 JSON，或通过浏览器打印保存 PDF。模型读音和翻译可在导出 JSON 中修正后重新导入。

特殊演唱读音依赖你提供的标音或参考罗马音；只凭文字无法确认音源。输入变化后请重新分析，页面会标记尚未同步的结果。
