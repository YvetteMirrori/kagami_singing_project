    A SMALL GUIDE

    使用指南

    日语歌词 分词、翻译、罗马音 逐词对齐可视化，便于扒歌与理解歌词含义。
    适合暂时不会日语、需要罗马音/中文空耳辅助学习日语歌进行过渡的爱好者。

    1. ① 检索，已有翻译直接用

      在歌曲名称框输入歌名，按 前缀匹配 检索；也可以打开「曲库」浏览。点击歌曲即可载入已审核的翻译，无需再次分析或支付模型费用。
      歌名请使用官方原名，从音乐软件复制，便于检索。

    2. ② 未收录的歌曲，自行分析

      在「模型设置」中填写模型服务地址、模型名称和 API Key。
      粘贴歌名与歌词，歌词可在音乐软件上copy仅日语or日语＋罗马音，点击「开始逐词分析」。特殊演唱读音依赖你提供的参考罗马音（如《夏霞》愛おしい，若不粘贴罗马音则可能标为ai）。
      当前可能出现的问题：歌词中标点符号较多会报错（如《Here, the world!》），粘贴的歌词与罗马音对应不上…请联系我。
      费用参考：使用 DeepSeek 处理一首《ロストワンの号哭》约 0.03 元人民币。后续会继续优化，降低用量和成本。

    3. ③ 检查结果，申请上传

      核对歌名、读音和翻译后，点击「上传」。按钮右侧出现 √，表示申请已送达后台。

    4. ④ 审核通过，收录曲库

      上传后由管理员审核，通过后会出现在检索结果和曲库中，方便其他人直接使用，减少重复分析的花费。
